# Mini-Game Implementations (Scheduled Milestone)

This directory is reserved for modular arcade game engines:

- `luckySpin.js` - Wheel spinner with multipliers
- `quickMath.js` - Timed mental arithmetic puzzle
- `numberGuess.js` - High/low binary search challenge
- `highCard.js` - Classic dealer card comparison
- `bombDefusal.js` - Multi-wire sequence challenge
